# Data Structures & Algorithms Assignment

## Instructions

### 1. Team Formation

Form groups of **exactly 3 students**. No individual submissions will be accepted.

### 2. Problem Selection

Each team must select **ONE combination** from the 30 available combinations listed below.

> **Important**: Combinations are first-come, first-served. Once a combination is selected by a team, it cannot be chosen by another team. Coordinate with your class representative to register your selection.

### 3. Deadline

**January 28, 2026** — All submissions must be completed by this date.

### 4. Presentation

- Presentation day will be announced.
- Each team member will have **5 minutes** to explain their portion of the work.
- All 3 members must present; absence results in 0 marks for that member — If anyone is absent and would like to present a reason, they'd have to take it up with the Instructor.

### 5. Submission Requirements

- Submit your project via **GitHub repository**.
- Send the GitHub link to the instructor **on or before the deadline**.
- Repository must include:
  - Source code (language-agnostic,you can choose any programming language)
  - README with instructions to run
  - Individual contributions documented

### 6. Academic Integrity

> **WARNING**: Plagiarism of any sort will result in **immediate disqualification** and a score of **0/20**.

This includes:

- Copying code from other teams - All code would be run through our plagiarism detection software.
- Using AI-generated solutions without understanding
- Submitting work that is not your own

### 7. Grading

Total marks: **20 points**
